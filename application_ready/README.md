# Application Ready - File Manager

This repository contains the complete, production-ready source code for the **Android File Manager** app built with Kotlin and Jetpack Compose.

## Project Highlights
- **Jetpack Compose & Material 3**: Clean, modern, responsive UI.
- **Drag-and-Drop & Cloud Storage**: Visual organizer and cloud drive features.
- **Media Player & Audio Overlay**: Built-in video modal player and persistent mini audio bar.
- **Intent Filter & File Picker Support**: Integrates seamlessly with external apps (like WhatsApp, Messenger, etc.) using `ACTION_GET_CONTENT`, `ACTION_OPEN_DOCUMENT`, and `ACTION_PICK`.
- **Dismissible Picker Mode**: Allows users entering via file picker intents to either select a file or dismiss the banner and browse the manager normally.

## Export & Push to GitHub
1. **Push to GitHub**: Click on the **GitHub** icon or **Settings** menu at the top right of AI Studio to directly push this repository to your GitHub account.
2. **Download ZIP**: You can also export the full project as a `.zip` file at any time using the AI Studio export feature in the top navigation bar.
3. **Build in Android Studio**: Open the project root in Android Studio, sync Gradle, and run `:app:assembleDebug` or `:app:assembleRelease`.
